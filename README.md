# English по полочкам — демо-сайт репетитора

Адаптивный одностраничный сайт для демонстрации репетиторам английского языка.

## Перед запуском для клиента

- заменить демонстрационный бренд на имя преподавателя;
- добавить подтверждённые образование, опыт и результаты;
- указать реальные стоимость, расписание и контакты;
- подключить форму заявки и политику обработки персональных данных;
- при необходимости добавить настоящие отзывы с согласия учеников.

## Публикация

Сайт подготовлен для GitHub Pages и не требует сборки.
